# 📚 Gerenciador-biblioteca
> Uma aplicação desktop para gerenciar o cadastro de livros e controlar empréstimos e devoluções de uma biblioteca acadêmica.

#### ☕ Versão do Java utilizada no desenvolvimento do trabalho
Microsoft OpenJDK 21.0.13.0.2

#### 🚀 Features
1. Cadastro de livros
2. Listagem de livros
3. Pesquisa de livros
4. Edição de livros
5. Exclusão de livros
6. Controle de empréstimos
7. Relatório da biblioteca
